# Configurations for the Stepper sample application

## Prerequisites
* Have a docker access
* Configure `docker-local.com` to point to the docker instance
* Configure `consul.local.com` to point to the consul IP
* Configure `settix_cluster` environment variable with value `docker-local.com`
* Have access to consul: http://consul.local.com:8500/

cmd
